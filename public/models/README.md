# Sample avatar

`VRM1_Constraint_Twist_Sample.vrm` is copied from the VRM Consortium
`vrm-specification` sample set:

https://github.com/vrm-c/vrm-specification/tree/master/samples/VRM1_Constraint_Twist_Sample

It is used as a cockpit/avatar rendering fixture because it exposes a humanoid
armature, face meshes, hair meshes, MToon materials, and VRM metadata. The
upstream sample directory is distributed under the VRM Public License 1.0.
